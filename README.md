# 16分の1の人生

MBTIタイプで、ひとりの人生を18歳から最期まで早送りするブラウザゲーム。
結果（享年・称号・人生のハイライト）を画像カードにして、Xでシェアできます。

- プレイ: https://sumisukekun.github.io/mbti-life/
- 1ファイル構成（`index.html`）、ビルド不要
- `ogp.png` … Xなどでリンクを貼ったときのカード画像（1200×630）

## 公開方法（GitHub Pages）
Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/ (root)`

※ 診断と人生のできごとはエンタメ用のフィクションです。
